UMA NOVA
HISTÓRIA.

Blue Lock: World Challenge é um projeto fan made inspirado no universo de Blue Lock.

O projeto nasceu da vontade de criar uma nova experiência dentro desse universo, reunindo história, personagens, capítulos e diferentes ideias em um único projeto.

Este site foi desenvolvido para reunir a obra e proporcionar aos leitores um espaço simples e organizado para acompanhar cada novo capítulo.
